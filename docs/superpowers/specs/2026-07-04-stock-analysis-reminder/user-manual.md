# 股票分析与提醒系统使用手册

## 1. 手册目标

本文档用于指导业务用户或管理员使用股票分析与提醒系统第一阶段功能，覆盖：

1. 市场节点查看
2. 股票分析查询
3. 关注股票监控
4. 提醒设置
5. 历史记录与复盘
6. 风险提示

## 2. 系统定位说明

本系统用于辅助理解市场节点、量价关系和做T结构，不用于自动下单。

请先明确：

1. 系统提供的是规则化辅助分析，不是收益保证
2. 所有建议都应结合你自己的交易计划
3. 生产环境分析基于真实行情数据

## 3. 功能总览

系统主要页面包括：

1. 市场节点
2. 股票分析
3. 行情监控
4. 自选股监控
5. 提醒设置
6. 历史记录

## 4. 市场节点页面怎么用

进入路径：

1. 登录后台
2. 打开“股票分析”
3. 进入“市场节点”

你会看到：

1. 当前市场处于哪个节点
2. 当前是否允许交易
3. 当前风险等级
4. 指数、成交额、涨停数、跌停数等市场概览
5. 历史节点记录

使用建议：

1. 先看“当前是否可交易”
2. 如果页面显示“继续观望”，不要急着进场
3. 如果页面显示“可进场”或“可小仓试错”，再去看个股分析

## 5. 股票分析页面怎么用

进入路径：

1. 打开“股票分析”页
2. 输入股票代码
3. 点击“查询”

你会看到三类结果：

1. 当前市场节点是否支持交易这只股票
2. 当前量价关系属于什么类型
3. 当前是否适合做T，以及支撑位、压力位、买卖区间

重点看这几项：

1. `量价类型`
2. `股价位置`
3. `建议动作`
4. `是否适合做T`
5. `支撑位 / 压力位`
6. `结构失效条件`

使用建议：

1. 如果市场节点不支持交易，优先观望
2. 如果量价结构不好，不要只因为价格便宜就冲动买入
3. 如果做T结论为“不适合”，不要强行做T

## 6. 如何把股票加入监控

在股票分析页查询后：

1. 点击“加入监控”
2. 选择采集级别
3. 设置采集周期
4. 选择是否启用分时采集、做T监控、价格提醒、信号提醒
5. 保存

采集级别说明：

1. `NORMAL`
说明：普通关注，低频监控

2. `KEY`
说明：重点关注，中频监控

3. `CORE`
说明：核心关注，高优先级监控

## 7. 自选股监控页面怎么用

进入路径：

1. 打开“自选股监控”

你会看到列表字段：

1. 股票代码
2. 股票名称
3. 采集级别
4. 采集周期
5. 最近采集时间
6. 最近分析结论
7. 最近提醒时间
8. 当前是否适合做T

你可以执行的操作：

1. 查看图表
2. 调整采集配置
3. 查看分析记录
4. 暂停监控
5. 恢复监控

使用建议：

1. 把真正重点看的股票设为 `KEY` 或 `CORE`
2. 长期不看的股票可以暂停监控，减少无效提醒

## 8. 行情监控页面怎么用

进入路径：

1. 从自选股监控页点击“查看图表”
2. 或打开“行情监控”页后选择股票

你会看到：

1. K 线图
2. 成交量柱状图
3. 支撑位
4. 压力位
5. 三重底低点标记
6. 最近量价信号
7. 最近提醒时间轴

使用建议：

1. 看图时先看支撑位和压力位
2. 再看量价结论是否和图形一致
3. 如果系统已经标注结构失效，不要继续按旧计划硬做T

## 9. 提醒设置页面怎么用

进入路径：

1. 打开“提醒设置”

页面分为两部分：

1. 提醒渠道配置
2. 提醒规则配置

### 9.1 渠道配置

可配置：

1. 站内信
2. WxPusher
3. 邮件，如果系统已接入

建议先做：

1. 启用一种渠道
2. 点击“测试发送”
3. 确认自己能收到消息

### 9.2 提醒规则配置

你可以配置：

1. 市场节点提醒
2. 量价提醒
3. 做T买点提醒
4. 做T卖点提醒
5. 结构失效提醒

建议使用方式：

1. 重要股票绑定更高优先级提醒
2. 避免给所有股票都开所有提醒，减少噪音
3. 合理设置冷却时间，避免连续轰炸

## 10. 历史记录页面怎么用

进入路径：

1. 打开“历史记录”

页签包括：

1. 分析记录
2. 提醒记录
3. 交易记录

### 10.1 分析记录

用于回看：

1. 当时市场节点
2. 当时量价结论
3. 当时做T结论
4. 当时系统建议

### 10.2 提醒记录

用于回看：

1. 什么时候触发
2. 因为什么触发
3. 发给了哪个渠道
4. 是否发送成功

### 10.3 交易记录

用于记录你自己的实际买卖：

1. 买入价
2. 卖出价
3. 收益率
4. 当时系统建议
5. 个人复盘备注

## 11. 推荐使用流程

建议每天使用顺序：

1. 先打开“市场节点”判断今天是交易窗口还是观望窗口
2. 再用“股票分析”查看目标股票是否符合量价和做T条件
3. 把重点股票加入监控
4. 在“提醒设置”里配置渠道和规则
5. 盘中关注“自选股监控”和“行情监控”
6. 盘后到“历史记录”做复盘

## 12. 典型使用场景

### 场景一：今天能不能开仓

操作：

1. 打开市场节点页
2. 查看当前节点和风险等级

判断：

1. 如果是增量共振点或分歧转一致点，可继续分析个股
2. 如果是观望或高风险状态，暂缓进场

### 场景二：某只股票适不适合做T

操作：

1. 在股票分析页输入代码
2. 查看量价分析与做T建议

判断：

1. 如果量价结构不佳，放弃做T
2. 如果系统提示适合做T，再看支撑位和压力位

### 场景三：我只想盯几只重点股票

操作：

1. 将目标股票加入监控
2. 设置 `KEY` 或 `CORE`
3. 开启价格提醒和信号提醒

结果：

1. 系统会对这些股票进行专门采集
2. 触发条件时主动推送提醒

## 13. 常见问题

### 13.1 为什么查询不到结果

可能原因：

1. 股票代码输入错误
2. 真实数据源暂时不可用
3. 当前股票缺少足够历史数据

### 13.2 为什么没收到提醒

可能原因：

1. 渠道没启用
2. 规则没启用
3. 冷却时间内不重复发送
4. 当前条件没有真正触发

### 13.3 为什么系统提示不适合做T

可能原因：

1. 股票不在低位横盘结构
2. 三重底结构未成立
3. 跌破关键支撑位
4. 波动空间不足以覆盖成本

## 14. 风险提示

请务必注意：

1. 本系统仅提供辅助分析，不构成任何投资建议
2. 股市有风险，投资需谨慎
3. 做T前提是结构没有破坏，失效时要及时停手
4. 不要因为系统提示而忽视你自己的仓位管理和风险控制

## 15. 最佳实践建议

1. 不要监控过多股票，先聚焦少量重点标的
2. 不要把所有提醒都打开，避免噪音过多
3. 盘后多看历史记录和交易记录，持续优化自己的节奏
4. 如果某类规则经常不适合你的风格，可以在参数配置里逐步调整

## 16. 结论

这套系统最适合这样使用：

1. 用市场节点决定“要不要交易”
2. 用量价分析决定“值不值得看”
3. 用做T分析决定“怎么买、怎么卖、什么时候停手”
4. 用提醒和历史记录把整个过程固定下来

如果按这个流程使用，系统的价值就不是替你拍板，而是帮你把交易纪律变得可执行、可提醒、可复盘。
