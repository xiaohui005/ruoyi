# 自选股、推荐页与买卖价关系说明

## 1. 这三个概念分别是干什么的

### 1.1 自选股

自选股页面的核心职责是“登记你自己长期或阶段性重点关注的股票”。

它本质上是一个关注列表，不等于买入信号列表，也不等于系统已经确认可以买的列表。

你把股票加入自选股，主要是为了：

- 让系统专门采集这只股票的行情
- 让系统持续分析这只股票
- 让系统在满足提醒条件时推送消息
- 让你能在一个地方集中查看最近分析、最近提醒、最新建议

所以，自选股和推荐价不是同一个概念。

自选股回答的是：

- “这只股票是不是我想重点跟踪的？”

而不是：

- “这只股票现在是不是已经可以下单了？”

### 1.2 推荐页

推荐页的职责是“从已启用的自选股里，挑出当前仍值得看的标的，并展示系统最近一次分析结论”。

当前系统逻辑下，推荐页不是全市场选股器，而是：

- 先从“已启用的自选股”里取股票
- 再读取每只股票最近一次分析记录
- 只保留建议动作属于以下范围的记录：
  - `BUY`
  - `T_STRATEGY`
  - `OBSERVE`

也就是说，推荐页现在的含义更接近：

- “这些自选股当前还有继续跟踪价值”

而不是：

- “只有完全达标才能进推荐页”

## 2. 你刚才理解的两个问题，正确答案是什么

### 2.1 自选股是不是只用来选择自己关注的股票

是。

这个理解是对的。

自选股首先是“关注池”，它的第一职责就是把你要盯的股票收进来，便于后续采集、分析、提醒。

### 2.2 推荐页是不是只有达标的才能进入

严格来说，不是。

按当前系统实现，推荐页不是只放“已经完全达标、可以马上买入”的股票。

它会放三类股票：

- `BUY`：已经满足系统定义的买入型条件
- `T_STRATEGY`：满足做T观察或执行条件
- `OBSERVE`：还没到直接买点，但仍值得继续观察

所以推荐页现在更像“候选池”或“优先关注池”，不是纯粹的“下单池”。

## 3. 买入价和卖出价现在系统会不会算

会算。

系统现在已经能给出以下价格信息：

- 支撑位
- 压力位
- 买入区间
- 卖出区间
- 失效条件

这些值当前在“股票分析”页里已经能看到。

## 4. 你现在为什么会感觉信息不完整

因为系统虽然已经算出了买卖价格，但没有把这些价格同步展示到“自选股页”和“推荐页”。

当前页面职责分布是这样的：

- 股票分析页：能看到完整买卖价
- 自选股页：主要看关注、采集、提醒状态
- 推荐页：主要看建议动作、风险等级、推荐原因

这就导致一个现实问题：

- 你把股票加入自选后，能看到“值得关注”
- 你在推荐页里，能看到“建议是买入 / 做T / 观察”
- 但你不能直接在这两个页面看到“具体在哪个价格买、在哪个价格卖”

所以你现在的困惑是成立的。

## 5. 当前系统应该怎样理解才不容易用错

建议你把三者分开理解：

### 5.1 自选股

表示“我要重点盯它”。

### 5.2 推荐页

表示“它现在在我关注池里，属于应该优先看的对象”。

### 5.3 买卖价

表示“如果要执行，系统建议的价格边界是什么”。

这三个应该形成一条链路：

1. 先把你要长期或阶段性关注的股票放进自选股
2. 系统持续采集、分析、提醒
3. 推荐页把当前值得优先看的股票挑出来
4. 你再结合买入区间、卖出区间、失效条件去执行

## 6. 目前缺少的不是算法，而是展示闭环

当前真正缺的不是“系统不会算”，而是“系统没有把算好的价格放到你最常看的页面上”。

因此，后续如果要优化，最合理的方向不是重写分析逻辑，而是补展示闭环：

- 在推荐页展示：
  - 支撑位
  - 买入区间
  - 卖出区间
  - 失效条件
- 在自选股页展示：
  - 支撑位
  - 买入区间
  - 卖出区间
  - 当前价是否进入买入区间

## 7. 一句话结论

一句话总结就是：

- 自选股是“关注池”
- 推荐页是“优先观察池”
- 买卖价格是“执行边界”

你现在的问题不是理解错了，而是页面还没有把这三层信息完整串起来。
